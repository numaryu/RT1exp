## 計算モデル

単一温度・等方Maxwell電子，単一イオン種（H⁺，D⁺，He⁺），準中性，非相対論，弱結合を仮定します．初期値は例示値で，特定放電の測定値ではありません．

衝突・温度平衡化，代表自由行程，周波数，ラーマー半径，電子Debye長，Alfvén速度，β，磁化率と無次元量を計算します．電子熱速度優勢の近似を用い，熱速度は√(2eT/m)に統一しています．高温・低温電子の共存，温度異方性，中性粒子衝突，電荷交換，磁場形状，バウンス平均は未実装です．

衝突率とCoulomb対数の参考：A. Beresnyak, 2023 NRL Plasma Formulary, pp. 28–34．定義はページ下部にも記載しています．

## 定義式の表示

ページ下部の「表示中のパラメータの定義式」に，選択中の結果タブの各量の式を表示します．「入力・記号・モデルの定義」で記号，単位，温度換算，熱速度規約と近似条件を確認できます．MathMLを使うため外部ライブラリやネット接続は不要です．
