# RT-1 Plasma Calculator

RT-1の局所プラズマパラメータから衝突率・時間・長さ・無次元量を計算する静的ページです．外部ライブラリ，インストール，ビルドは不要です．

## ファイルと編集場所

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構成，入力欄，説明文，モデル・記号の説明 |
| `style.css` | 配置，色，文字サイズ，スマートフォン用の表示 |
| `physics.js` | 物理定数，数値計算，入力検証と近似の警告 |
| `definitions.js` | 結果の名前・記号・単位，表示する定義式と説明文 |
| `app.js` | 入力の読み取り，再計算，結果・式・走査グラフの表示 |
| `README.md` | この説明書 |

### 定義式と説明を直す

`definitions.js` の `formulas` に各パラメータの項目があります．たとえば `lambdaE` が電子の代表自由行程です．各項目は「表示する式」「説明文」の2つに分けています．同ファイルの `groups` で名称・記号・単位・表示順を変更できます．

式にはブラウザ標準のMathMLを使っています．`frac(a, b)` は分数，`sqrt(a)` は平方根，`sup(a, 2)` は2乗，`sub('n', 'e')` は下付き添字の記号です．

**表示する定義式の変更は数値計算には反映されません．** 計算式を変更するときは `physics.js` の対応する項目も修正してください．

### 画面・初期値を直す

表示する説明文や入力欄の初期値（`value`）は `index.html` で編集できます．`physics.js` の `defaults` は計算の既定値です．イオン種の入力選択肢には質量比mᵢ/mₚを使っています（H⁺: 1，D⁺: 2，He⁺: 4）．

## 手元で開く

6ファイルを同じフォルダに置き，`index.html` をブラウザで開いてください．通常のスクリプトを順番に読み込む構成なので，ローカルサーバーなしでも動作します．

## GitHub Pages

リポジトリ直下に6ファイルを配置してcommit/pushしてください．既存の `index.html` と `README.md` は上書きします．

Settings → Pages → Build and deploymentで「Deploy from a branch」，ブランチ「main」，フォルダ「/(root)」を選択してSaveします．設定済みならpush後に更新されます．

## 計算モデル

単一温度・等方Maxwell電子，単一イオン種，準中性，非相対論，弱結合を仮定します．衝突率と自動Coulomb対数には電子熱速度優勢の近似を使用します．熱速度は√(2eT/m)に統一しています．

初期値は例示値で，特定放電の測定値ではありません．高温・低温電子の共存，温度異方性，中性粒子衝突，電荷交換，磁場形状，バウンス平均は未実装です．

参考：A. Beresnyak, *2023 NRL Plasma Formulary*, pp. 28–34．定義と近似条件はページ下部にも記載しています．
