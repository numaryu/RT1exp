定義式・計算モデル

共通の記号・単位・仮定

入力値 \(n_{\mathrm{e}}\) は局所電子密度 [\(\mathrm{m}^{-3}\)]， \(T_{\mathrm{e}}\)・\(T_{\mathrm{i}}\) は電子・イオン温度 [eV]， \(B\) は局所磁場の強さ [T]，\(L\) は代表長さ [m]． \(L\) はユーザーが指定する比較用の長さで，磁力線長や勾配長とは自動では対応しない．

物理定数 \(e=1.60\times10^{-19}\) [\(\mathrm{C}\)] は正の素電荷，\(m_{\mathrm{e}}=9.11\times10^{-31}\) [\(\mathrm{kg}\)]・\(m_{\mathrm{p}}=1.67\times10^{-27}\) [\(\mathrm{kg}\)] は電子・陽子質量， \(\varepsilon_0=1/(c^2 \mu_{0}) \) [\(\mathrm{F}/\mathrm{m}\)]・\(\mu_0=4\pi\times10^{-7}\) [\(\mathrm{H}/\mathrm{m}\)] は真空の誘電率・透磁率，\(c=2.998\times10^8\) [\(\mathrm{m}/\mathrm{s}\)] は光速, \(k_{\mathrm{B}}=1.38\times10^{-23}\) [\(\mathrm{J}/\mathrm{K}\)] はボルツマン定数． 衝突の式では \(K\equiv e^2/(4\pi\varepsilon_0)\) と略記する．

粒子種 単一温度・等方Maxwell電子を仮定する．電子の質量，電荷を \(m_{\mathrm{e}}\)，\(q_{\mathrm{e}}=-e\) とする． イオンは質量数 \(A\) の単一種で，単一電荷 \(Z\) を持つと仮定する． イオンの質量 \(m_{\mathrm{i}}=A m_{\mathrm{p}}\), 電荷 \(q_{\mathrm{i}}=Z e\)，密度 \(n_{\mathrm{i}}=n_{\mathrm{e}}/Z\)　（準中性条件を仮定）． 選択できる \(\mathrm{H}^{+}\)，\(\mathrm{D}^{+}\)，\(\mathrm{He}^{+}\) はすべて \(Z=1\)で，質量数は \(\mathrm{H}^{+}\): \(A=1\)，\(\mathrm{D}^{+}\): \(A=2\)，\(\mathrm{He}^{+}\): \(A=4\)の近似値を用いる．

周波数と角周波数 周波数を \(f\) [\(\mathrm{Hz}\)]，角周波数を \(\omega\) [\(\mathrm{rad}\,\mathrm{s}^{-1}\)] とする． \(2 \pi f = \omega\)．

温度の単位 入力時のみ [\(\mathrm{eV}\)] の単位で与えるが，以下の計算では [\(\mathrm{J}\)] に換算する．

適用範囲 非相対論・弱結合を仮定する．電子–イオン衝突周波数と自動Coulomb対数は 電子熱速度優勢の近似 \(T_{\mathrm{e}}\gg T_{\mathrm{i}}m_{\mathrm{e}}/m_{\mathrm{i}}\) を用いる． 高温・低温電子の共存，温度異方性，中性粒子衝突，電荷交換，磁場形状とバウンス平均は含めない．

各パラメータの定義式

電子–イオン衝突周波数: \(\nu_{\mathrm{ei}}\) [\(\mathrm{s}^{-1}\)]
\[ \nu_{\mathrm{ei}} = \frac{4\sqrt{2\pi}}{3} \frac{n_{\mathrm{i}} Z^2 K^2 \ln\Lambda_{\mathrm{ei}}} {\sqrt{m_{\mathrm{e}}}\,\theta_{\mathrm{e}}^{3/2}} \]

Maxwell電子のイオンに対する運動量緩和率．電子熱速度優勢の極限．

イオン–イオン衝突周波数: \(\nu_{\mathrm{ii}}\) [\(\mathrm{s}^{-1}\)]
\[ \nu_{\mathrm{ii}} = \frac{4\sqrt{\pi}}{3} \frac{n_{\mathrm{i}} Z^4 K^2 \ln\Lambda_{\mathrm{ii}}} {\sqrt{m_{\mathrm{i}}}\,\theta_{\mathrm{i}}^{3/2}} \]

同種イオンの衝突周波数（NRLの定義）．

電子温度平衡化時間: \(\tau^{E}_{\mathrm{ei}}\) [\(\mathrm{s}\)]
\[ \tau^{E}_{\mathrm{ei}} = \frac{3m_{\mathrm{e}}m_{\mathrm{i}}} {8\sqrt{2\pi}\,n_{\mathrm{i}}Z^2K^2\ln\Lambda_{\mathrm{ei}}} \left( \frac{\theta_{\mathrm{e}}}{m_{\mathrm{e}}} + \frac{\theta_{\mathrm{i}}}{m_{\mathrm{i}}} \right)^{3/2} \]

電子温度の変化率：\(\mathrm{d}T_{\mathrm{e}}/\mathrm{d}t = (T_{\mathrm{i}}-T_{\mathrm{e}})/\tau^{E}_{\mathrm{ei}}\)．相手の温度を固定したときの電子温度の平衡化時間を表す．両種が変化するとき，温度差の瞬時緩和時間は \(\tau^{E}_{\mathrm{ei}}/(1+Z)\)．

電子–イオン Coulomb対数: \(\ln\Lambda_{\mathrm{ei}}\)
\[ \ln\Lambda_{\mathrm{ei}} = \begin{cases} 23 - \ln\!\left(\dfrac{\sqrt{n_{\mathrm{e,c}}}\,Z}{T_{\mathrm{e}}^{3/2}}\right), & T_{\mathrm{e}} < 10Z^2\,\mathrm{eV}, \\[6pt] 24 - \ln\!\left(\dfrac{\sqrt{n_{\mathrm{e,c}}}}{T_{\mathrm{e}}}\right), & T_{\mathrm{e}} \ge 10Z^2\,\mathrm{eV}. \end{cases} \]

自動モードの式．\(n_{\mathrm{e,c}}\) は \(\mathrm{cm}^{-3}\) 単位の電子密度の数値（入力 \(n_{\mathrm{e}}\) の \(10^{-6}\) 倍），\(T_{\mathrm{e}}\) はeV単位の数値．手動モードでは入力値をそのまま使用．

イオン–イオン Coulomb対数: \(\ln\Lambda_{\mathrm{ii}}\)
\[ \ln\Lambda_{\mathrm{ii}} = 23 - \ln\!\left( \frac{\sqrt{2n_{\mathrm{i,c}}}\,Z^3}{T_{\mathrm{i}}^{3/2}} \right) \]

自動モードの式．\(n_{\mathrm{i,c}}\) は \(\mathrm{cm}^{-3}\) 単位のイオン密度の数値，\(T_{\mathrm{i}}\) はeV単位の数値．手動モードでは入力値をそのまま使用．

平均自由行程: \(\lambda_{s}\) [\(\mathrm{m}\)]
\[ \lambda_{\mathrm{s}} = \frac{v_{\mathrm{th,s}}}{\nu_{s}} \]

電子については，電子–イオン衝突周波数 \(\nu_{s}=\nu_{\mathrm{ei}}\) で衝突周波数を代表して計算する．全衝突過程を合計した輸送平均自由行程ではない． イオンについては，同種イオン衝突周波数 \(\nu_{s}=\nu_{\mathrm{ii}}\) に基づいて計算する．

熱速度: \(v_{\mathrm{th},s}\) [\(\mathrm{m}/\mathrm{s}\)]
\[ v_{\mathrm{th},s} = \sqrt{\frac{2T_s}{m_s}} \]
熱速度: \(v_{\mathrm{th},s}\) [\(\mathrm{m}/\mathrm{s}\)]
\[ v_{\mathrm{th},s} = \sqrt{\frac{2T_s}{m_s}} \]
サイクロトロン角周波数: \(\Omega_{s}\) [\(\mathrm{s}^{-1}\)]　
\[ \Omega_{s} = \frac{|q_s|B}{m_s} \]

また，サイクロトロン周波数 \(f_s = \Omega_{s}/(2\pi)\) [\(\mathrm{Hz}\)]．

電子サイクロトロン周波数: \(f_{\mathrm{ce}}\) [\(\mathrm{s}^{-1}\)]
\[ f_{\mathrm{ce}} = \frac{\Omega_{\mathrm{e}}}{2\pi} = \frac{eB}{2\pi m_{\mathrm{e}}} \]

\(\Omega_{\mathrm{e}} = eB/m_{\mathrm{e}}\) は角周波数 [\(\mathrm{rad}\,\mathrm{s}^{-1}\)]．

イオンサイクロトロン周波数: \(f_{\mathrm{ci}}\) [\(\mathrm{s}^{-1}\)]
\[ f_{\mathrm{ci}} = \frac{\Omega_{\mathrm{i}}}{2\pi} = \frac{ZeB}{2\pi m_{\mathrm{i}}} \]

\(\Omega_{\mathrm{i}} = ZeB/m_{\mathrm{i}}\) は角周波数 [\(\mathrm{rad}\,\mathrm{s}^{-1}\)]．

電子プラズマ周波数: \(f_{\mathrm{pe}}\) [\(\mathrm{s}^{-1}\)]
\[ f_{\mathrm{pe}} = \frac{1}{2\pi}\sqrt{\frac{n_{\mathrm{e}}e^2}{\varepsilon_0 m_{\mathrm{e}}}} \]

\(\omega_{\mathrm{pe}} = \sqrt{n_{\mathrm{e}}e^2/(\varepsilon_0 m_{\mathrm{e}})}\)，\(f_{\mathrm{pe}} = \omega_{\mathrm{pe}}/(2\pi)\)．

電子ラーマ半径: \(\rho_{\mathrm{e}}\) [\(\mathrm{m}\)]
\[ \rho_{\mathrm{e}} = \frac{v_{\mathrm{th},\mathrm{e}}}{\Omega_{\mathrm{e}}} = \frac{\sqrt{2m_{\mathrm{e}}\theta_{\mathrm{e}}}}{eB} \]

熱速度の定義に対応する代表ラーマ半径．

イオンラーマ半径: \(\rho_{\mathrm{i}}\) [\(\mathrm{m}\)]
\[ \rho_{\mathrm{i}} = \frac{v_{\mathrm{th},\mathrm{i}}}{\Omega_{\mathrm{i}}} = \frac{\sqrt{2m_{\mathrm{i}}\theta_{\mathrm{i}}}}{ZeB} \]

熱速度の定義に対応する代表ラーマ半径．

電子Debye長: \(\lambda_{\mathrm{De}}\) [\(\mathrm{m}\)]
\[ \lambda_{\mathrm{De}} = \sqrt{\frac{\varepsilon_0\theta_{\mathrm{e}}}{n_{\mathrm{e}}e^2}} \]

電子のみのDebye長．イオンの遮蔽寄与は含めない．

Alfvén速度: \(v_{\mathrm{A}}\) [\(\mathrm{m \cdot s^{-1}}\)]
\[ v_{\mathrm{A}} = \frac{B}{\sqrt{\mu_0 n_{\mathrm{i}} m_{\mathrm{i}}}} \]

イオン質量密度に基づくAlfvén速度．電子質量を無視．

電子ベータ: \(\beta_{\mathrm{e}}\)
\[ \beta_{\mathrm{e}} = \frac{2\mu_0 n_{\mathrm{e}}\theta_{\mathrm{e}}}{B^2} \]

等方電子圧力 \(p_{\mathrm{e}} = n_{\mathrm{e}}\theta_{\mathrm{e}}\) と磁気圧の比．

イオンベータ: \(\beta_{\mathrm{i}}\)
\[ \beta_{\mathrm{i}} = \frac{2\mu_0 n_{\mathrm{i}}\theta_{\mathrm{i}}}{B^2} \]

等方イオン圧力 \(p_{\mathrm{i}} = n_{\mathrm{i}}\theta_{\mathrm{i}}\) と磁気圧の比．

電子磁化パラメータ: \(\Omega_{\mathrm{e}}/\nu_{\mathrm{ei}}\)
\[ \frac{\Omega_{\mathrm{e}}}{\nu_{\mathrm{ei}}} = \frac{eB}{m_{\mathrm{e}}\nu_{\mathrm{ei}}} \]

角周波数と衝突周波数の比．\(f_{\mathrm{ce}}/\nu_{\mathrm{ei}}\) とは \(2\pi\) の係数が異なる．

イオン磁化パラメータ: \(\Omega_{\mathrm{i}}/\nu_{\mathrm{ii}}\)
\[ \frac{\Omega_{\mathrm{i}}}{\nu_{\mathrm{ii}}} = \frac{ZeB}{m_{\mathrm{i}}\nu_{\mathrm{ii}}} \]

角周波数と同種イオン衝突周波数の比．

電子Knudsen数: \(\lambda_{\mathrm{e}}/L\)
\[ \mathrm{Kn}_{\mathrm{e}} = \frac{\lambda_{\mathrm{e}}}{L} = \frac{v_{\mathrm{th},\mathrm{e}}}{\nu_{\mathrm{ei}}L} \]

指定した代表長さ \(L\) に対するKnudsen数．

イオンKnudsen数: \(\lambda_{\mathrm{i}}/L\)
\[ \mathrm{Kn}_{\mathrm{i}} = \frac{\lambda_{\mathrm{i}}}{L} = \frac{v_{\mathrm{th},\mathrm{i}}}{\nu_{\mathrm{ii}}L} \]

指定した代表長さ \(L\) に対するKnudsen数．

規格化ラーマ半径: \(\rho_{\mathrm{i}}/L\)
\[ \rho_* = \frac{\rho_{\mathrm{i}}}{L} = \frac{v_{\mathrm{th},\mathrm{i}}}{\Omega_{\mathrm{i}}L} \]

このページでは \(\rho_* = \rho_{\mathrm{i}}/L\) と定義．
